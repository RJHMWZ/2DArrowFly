Hue Relay 常用调试

打开 Unity 菜单 Tools > Hue Relay > 调试面板。仅编辑器可用，正式构建不包含窗口或调试命令。

为什么还显示 3 / 3 / 3
PowerUps.asset 的初始数量只在本地库存首次建立时生效。已有 cc_powerups_v1 存档优先，改配置不会覆盖旧库存。
点击“恢复配置默认数量”将当前库存设为配置值（当前为 0 / 0 / 0）。Play 模式下立即刷新 HUD 并保存，退出重进仍保留。
无需删除所有 PlayerPrefs，不影响其他 SDK、声音设置或留存奖励领取记录。

常用操作
- 道具：自定义三个余额、恢复默认、全部清零、设为各 10 个；停止运行时也可修改本地库存。
- 关卡：Play 模式指定 1～LevelCount 关、重玩、进入无尽。跳关本身不改变已解锁进度。
- 胜负：快速胜利／失败从当前棋盘重置后开始，立即展示结算，不测试得分动画；胜利会真实保存通关进度并增加广告通关计数。无尽模式保持无尽结算。
- 教学：重播首次教学会清除已完成标记；标记完成可跳过教学恢复棋盘。
- 存档：重置闯关进度、标记全通关、清零最高分。这些操作有确认框，并只修改相关键。
- 广告：完整观看、提前关闭、播放失败、无填充、无回调五种模拟。使用临时配置副本，不修改 AdPolicy.asset，不请求真实广告。

测试流程
1. 原有库存仍为 3：停止或运行游戏，打开调试面板，点击“恢复配置默认数量”，运行中检查 HUD 为 0 / 0 / 0。
2. 广告补充：Play 模式标记教学完成，启用完整观看模拟，道具全部清零，在游戏内点击提示，再点击 Watch Ad，确认仅提示 +1。
3. 取消／失败：切换对应模拟结果并点击更新，重复上述流程，库存应保持 0；弹窗可以关闭。
4. 插屏：保留默认 120 秒会话前台等待和 3 次通关门槛，使用第 4 关及以后快速胜利／失败，检查广告先播放、关闭后才弹出结算面板；两个结算时机共用频控；下一关、Home、Retry 不触发广告。
5. 超时：选择无回调，等待原配置播放超时，或者点击“终止模拟广告并恢复正常后端”提前退出；不发奖励。
6. 教学／进度：重播教学确认不消耗库存；重置闯关进度后从第 1 关开始，道具保留。

注意
- 启用／更新模拟、恢复正常后端均重新初始化广告会话，计数及等待时间重新开始。
- 广告模拟仍需完成教学，仍遵守真实冷却、奖励和插屏保护条件。
- 广告播放或棋盘生成中禁用修改命令，避免旧回调影响新棋盘；无回调模拟可用专门按钮终止。
- 关闭调试窗口或退出 Play 自动恢复正常广告后端。Unity Editor 的正常后端不展示真实 TikTok 广告。
- 道具编辑会保存本地测试存档，不是临时预览。建议使用测试环境进行测试。
