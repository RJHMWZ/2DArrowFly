# Hue Relay：100 关初版设计

所有关卡均提供不使用道具的标准连锁通关解。基准步数由离线 A* 求解器证明；难度分由箭头数量、依赖深度、多重阻挡、折线、随机出手的步数损失和道具余量共同评估，并映射到 1–100 分。

## 可复现与验收

- 生成：`python Tools/HueRelay/BuildCampaign.py`。固定种子 20261118100。
- 运行数据：`Assets/HueRelay/Resources/HueRelay/Data/Levels.json`；每关含坐标、规则、标准解和评估指标。
- 每关独立布局，不以旋转或换色复制凑数；坐标不重叠、路径连续、无自阻挡，箭头数不超过 30。
- 游戏第 100 关后进入原有无尽模式。TT 配置与 SDK 设置不参与本次修改。
